How to Install

1

Download

Grab the APK (Android) or EXE (Windows) above — the latest version is always pre-selected.

2

Android

Open the APK. Allow "install unknown apps" from your browser / file manager. Grant permissions when Venom asks.

3

Windows

Double-click the EXE — it's portable, no installation needed. Runs anywhere, from a USB stick too.

4

Add API key

Open Settings (gear icon) → paste your Gemini API key → say "Wake Venom" and enjoy. 🎙️
